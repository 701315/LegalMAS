# ЗАДАЧА

Напиши раздел «Сводка по глобальным чекам» — ровно 2–4 предложения,
одним абзацем, без списков и bullet points.

Раскрой, в следующем порядке:
1. Сколько глобальных чеков применено всего.
2. Какие чеки выявили замечания: название чека, количество замечаний,
   максимальная серьёзность (critical / high / medium) — все в одном
   перечислении через запятую.
3. Сколько чеков завершены без замечаний. Если ноль — напиши
   «Чеков, завершённых без замечаний, нет.»

# ПРАВИЛА

## Обязательные

1. **Прослеживаемость**: каждое число ДОЛЖНО присутствовать во ВХОДНЫХ
   ДАННЫХ ровно как написано. Не округляй, не аппроксимируй, не меняй.
2. **Названия чеков — дословно из ВХОДНЫХ ДАННЫХ**: не перефразируй,
   не переводи, не сокращай.
3. **Только цифры**: числа пиши ЦИФРАМИ («2 чека», не «два чека»;
   «3 замечания», не «три замечания»).
4. **Деловой тон**: формальный юридический русский язык, сдержанный,
   конкретный. Активный залог: «применено», «выявлено», «проверено».
5. **Длина**: ровно 2–4 предложения. Один абзац. Без bullet points.

## Запрещено

1. **Никаких вымыслов**: не добавляй чеки, риски, документы, юридические
   выводы или факты, которых нет во ВХОДНЫХ ДАННЫХ.
2. **Никаких юридических ссылок**: не упоминай номера статей, кодексов,
   законов, федеральных актов, судебных решений, нормативных документов.
   Запрещённые примеры: любые номера статей, названия кодексов и законов
   (ГК РФ, НК РФ, ЗК РФ, ФЗ и т.п.). Ты — редактор отчёта,
   не юридический консультант. Единственный источник фактов — ВХОДНЫЕ ДАННЫЕ.
3. **Никаких M&A-терминов без источника**: не используй «SPA»,
   «Покупатель», «Продавец», «Завершение», «Целевая компания», если они
   буквально не встречаются во ВХОДНЫХ ДАННЫХ.
4. **Никакого «филлера»**: «в рамках проведённого анализа», «следует
   отметить», «необходимо подчеркнуть», «в заключение».
5. **Никакого форматирования**: без Markdown, без заголовков, без списков,
   без bullet points. Только проза.
6. **Никакой самопохвалы**: не описывай анализ как «комплексный»,
   «тщательный», «всесторонний» — констатируй только факты.
7. **Никаких рекомендаций**: не указывай читателю, что делать, — это не
   место для рекомендаций.
8. **Никаких чисел из примеров**: числа в примере ниже — иллюстративные.
   Используй ТОЛЬКО числа из ВХОДНЫХ ДАННЫХ.

## Grounding-правила (критично)

1. **Правило честности**: если требуемый факт отсутствует во ВХОДНЫХ
   ДАННЫХ, НЕ выдумывай его. Пропусти или переформулируй, чтобы избежать
   пробела.
2. **Правило анти-предположений**: не заполняй пробелы по паттерну.
   Если что-то не указано — не считай это само собой разумеющимся.
3. **Правило анти-ассоциаций**: если во ВХОДНЫХ ДАННЫХ упомянуто название
   чека, типа документа или поля, которое ассоциируется с какой-либо
   нормой права, статьёй, законом или кодексом — это НЕ означает, что
   нужно упоминать эту норму. Не цитируй кодексы и законы, даже если
   название чека содержит отсылку к ним.
4. **Правило ограничения**: используй только ВХОДНЫЕ ДАННЫЕ. Не привлекай
   внешние знания, не ссылайся на нормы права, не цитируй кодексы.
