# Default runtime profile: CPU-only PyTorch wheels.
#
# Архитектурное правило:
# - requirements.txt = production/runtime default for CPU environments;
# - GPU deployments must NOT use this profile directly;
# - GPU runtime installs torch via Docker build arg ACCELERATOR=gpu
#   or Make target install-runtime-gpu / install-dev-gpu.
#
# Такой split делает install reproducible:
# - CPU machines не тянут CUDA wheels;
# - GPU deployments получают явный install path;
# - runtime code later can autodetect device (cuda/cpu), но wheel variant
#   выбирается на этапе install, а не во время работы.
--extra-index-url https://download.pytorch.org/whl/cpu
torch==2.5.1+cpu
